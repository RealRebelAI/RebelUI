# RebelUI

RebelUI is a lightweight, direct-to-ComfyUI generation interface built for users who want a cleaner, faster, more focused workflow without using ComfyUI's node graph for every generation.

It runs directly against your existing ComfyUI installation and model folders, while providing a streamlined interface for model selection, prompting, sampling, VRAM monitoring, output viewing, and persistent session settings.

RebelUI is currently focused on image generation workflows and includes dedicated support for modern ComfyUI model families such as Krea 2.

---

## Features

- Direct integration with an existing ComfyUI installation
- No separate model library required
- Automatic discovery of:
  - Diffusion models
  - GGUF diffusion models
  - Text encoders
  - GGUF text encoders
  - VAEs
- Support for FULL and GGUF model formats
- Native ComfyUI execution path for Krea 2
- Krea 2 Turbo INT8 / FP8 support
- Dynamic ComfyUI sampler and scheduler discovery
- Architecture presets
- Persistent session memory
- Persistent UI layout settings
- Live CUDA VRAM monitoring
- Resizable left and right sidebars
- Resizable prompt and negative-prompt fields
- Resizable Run Log
- Independent scrolling for left and right control panels
- Hide / show model and control sidebars
- Output image viewer
- Theme system
- Compact and comfortable interface density modes
- Saved model, encoder, VAE, sampler, prompt, and generation settings
- Automatic browser launch support through a Windows `.bat` launcher
- Dark production-style interface designed for large desktop displays
